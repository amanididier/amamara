# Amamara Android APK

After you build the release APK (see `docs/MOBILE.md`), place it here as:

```text
public/downloads/amamara.apk
```

The marketing site **Download the app** button points to `/download`, which serves this file (or the Play Store once configured).

Until the APK exists, the download page guides users to install Amamara from Chrome (Add to Home Screen) — opens the studio with the red home-screen icon.
